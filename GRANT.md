# DealDost — Solana Grant Package

**Focus:** Solana community-support and transparent contribution infrastructure

## One-line description
DealDost is a Solana-based community support platform designed to make voluntary SOL contributions simple, transparent and publicly verifiable.

## Project summary
DealDost combines Solana wallet payments, QR-based contributions, public on-chain transaction visibility and social campaign sharing in a lightweight web experience. The current prototype is live and uses read-only Solana mainnet data for its public tracker.

The next phase will turn the prototype into reusable, open-source infrastructure for legitimate Solana community campaigns.

## Problem
Small community projects and creators often lack simple crypto contribution infrastructure. Traditional fundraising tools can add payment friction, geographic restrictions, processing dependencies and limited transparency. DealDost explores a Solana-native alternative where settlement happens directly on-chain and transaction activity can be independently verified.

## Why Solana
Solana provides the wallet ecosystem, fast low-cost settlement and public ledger needed for small community contributions. DealDost is designed specifically around SOL payments and Solana mainnet transaction verification rather than adding crypto as a secondary payment option.

## Current product
- SOL donation address and QR payment
- Amount selection and wallet-opening flow
- Phantom and Solflare wallet options
- Copy-address fallback
- Read-only public Solana mainnet tracker
- Transaction links to Solana Explorer
- Social sharing for WhatsApp, Telegram and X
- Promotion/referral attribution page
- No private keys or seed phrases stored
- No custody of supporter funds

## Roadmap
### Milestone 1 — Production foundation
Improve mobile UX, wallet/payment flow, RPC reliability, error handling, QR experience, documentation and transparency pages.

### Milestone 2 — Transparent funding dashboard
Improve transaction indexing, incoming transfer history, verification links, campaign statistics, RPC reliability and duplicate/failed-data handling.

### Milestone 3 — Reusable campaign system
Add unique campaign pages, configurable campaign wallets, QR generation, shareable URLs, attribution parameters and campaign-level public statistics.

### Milestone 4 — Open-source ecosystem release
Release reusable core components, developer documentation, deployment documentation, Solana integration examples and an example campaign template.

## Public-good and open-source commitment
Reusable technical components and documentation developed through the grant will be open-sourced where practical. The aim is to let other Solana builders learn from and deploy similar transparent contribution infrastructure.

## Security and trust model
DealDost will not custody supporter funds. The destination wallet will be displayed clearly. Users will be encouraged to verify wallet address, destination, transaction signature and Solana Explorer information. DealDost will never request seed phrases, private keys or wallet passwords.

Contributions are voluntary and are not investments, securities, guaranteed returns or profit-sharing arrangements.
