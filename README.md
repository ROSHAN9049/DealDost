# Binance AI Scanner

Binance Futures market scanner with Momentum and Scalping signals, paper trading, SL/TP, signal score, reasons and basic risk guard.

## Safety
- Paper trading only in V1.
- No Binance API keys are requested or stored in the browser.
- Live trading is reserved for a later backend stage with secure server-side credentials, testnet validation and explicit risk controls.

## Roadmap
1. V1 — public market scanner + paper trading
2. V2 — Binance Futures Testnet execution
3. V3 — micro live trading with manual approval
4. V4 — controlled automation + kill switch
